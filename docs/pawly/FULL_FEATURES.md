# Pawly feature coverage

The current feature table and recovery contracts are in [PAWLY.md](../../PAWLY.md).
Build instructions are in [BUILDING.md](BUILDING.md); verification and platform
limits are in [VERIFICATION.md](VERIFICATION.md).

Native lists cover quick cleanup, full cleanup previews, app inventory and related
files, project artifacts, installers, maintenance previews, disk browsing, health
and history. Final deep cleanup, uninstall, privileged maintenance and some settings
continue through the embedded original engine. These flows support both keyboard
input and visible control buttons.

Pawly does not claim every workflow is implemented as a fully native form. It does
not infer that a popular upstream project makes every GUI integration safe. The
original protection rules, exact target evidence and explicit confirmation remain
part of the execution path.
